# Draw Steel — Skills

Ruleset reference for `exploration-encounter`. Source: *Draw Steel Heroes* v1, Chapter 9, book pp. 254–257.

## Applying a skill to a Test

When a hero has a skill that applies to a [[tests|test]], they add **+2** to the roll.

- The **+2 is not an edge** — a test can stack skill-+2 with an edge.
- **At most one skill per test.**
- **Skills flex across characteristics.** A skill applies to a test using any characteristic that makes sense; Director has final say. (Climb usually Might, but Agility for balcony parkour. Intimidate is Presence when verbal, Might when tearing a log in half.)
- **Player justifies the skill.** The Director doesn't memorize skill reach; the player says "I think [skill] applies because [reason]." Director agrees or disagrees; their call stands.
- **No skill ≠ no chance.** A decent characteristic alone gives reasonable odds.

**Edges from features.** Some abilities grant an edge on tests made *with a specific skill* — to anyone making such a test, whether they have the skill or not (e.g., fog from *Blessing of Fortunate Weather* grants an edge on Hide-skill tests).

## Skill groups

Skills belong to one of five groups. Each group has a reward/consequence pattern the Director can default to.

### Crafting — *create, appraise, jury-rig; useful on rests/downtime.*

**Reward pattern:** leftover rare material, a buyer willing to pay extra, a jury-rig that lasts longer than it should.
**Consequence pattern:** wasted materials, wildly mis-estimated value, a jury-rig that hurts the wrong people.

| Skill | Use |
|---|---|
| Alchemy | Make bombs and potions |
| Architecture | Create buildings and vehicles |
| Blacksmithing | Forge metal armor and weapons |
| Carpentry | Create items out of wood |
| Cooking | Create delicious dishes |
| Fletching | Make ranged weapons and ammunition |
| Forgery | Create false badges, documents, and other items |
| Jewelry | Create bracelets, crowns, rings, and other jewelry |
| Mechanics | Build machines and clockwork items |
| Tailoring | Craft clothing of cloth or leather |

### Exploration — *physical traversal and obstacles; highest-impact group for exploration encounters.*

**Reward pattern:** let an ally in the same task auto-succeed, auto-succeed a follow-up, arrive early, learn about or avoid an upcoming hazard.
**Consequence pattern:** harm self / gear / allies, become lost, stumble into the thing you wanted to avoid.

| Skill | Use |
|---|---|
| Climb | Move up vertical surfaces |
| Drive | Control vehicles |
| Endurance | Remain engaged in strenuous activity over a long period of time |
| Gymnastics | Move across unsteady or narrow surfaces; tumble |
| Heal | Use mundane first aid |
| Jump | Leap vertical and horizontal distances |
| Lift | Pick up, carry, and throw heavy objects |
| Navigate | Read a map and travel without becoming lost |
| Ride | Ride and control a nonsapient mount, such as a horse |
| Swim | Move through deep liquid |

### Interpersonal — *social interaction; key in negotiations (Chapter 11).*

Applies only to creatures with emotions who can understand you — **except Handle Animals.**

**Reward pattern:** extra favor, item, or piece of information from the target.
**Consequence pattern:** target becomes angry/sad/embarrassed/offended — may ignore, storm off, smear by rumor, attack, betray, or blackmail.

| Skill | Use |
|---|---|
| Brag | Impress others with stories of your deeds |
| Empathize | Relate to someone on a personal level |
| Flirt | Attract romantic attention from someone |
| Gamble | Make bets with others |
| Handle Animals | Interact with nonsapient animal wildlife |
| Interrogate | Obtain information from a creature withholding it |
| Intimidate | Awe or scare a creature |
| Lead | Inspire people to action |
| Lie | Convince someone that a falsehood is true |
| Music | Perform music vocally or with an instrument |
| Perform | Engage in dance, oratory, acting, or some other physical performance |
| Persuade | Convince someone to agree with you through use of your charms and grace |
| Read Person | Read the emotions and body language of other creatures |

### Intrigue — *investigation, thievery, spycraft.*

**Reward pattern:** ally in same task auto-succeeds, auto-succeed a follow-up, extra info beyond what you sought, a clandestine side-task accomplished.
**Consequence pattern:** caught in the act, or missed detail puts you in danger (trap triggers, ambush).

| Skill | Use |
|---|---|
| Alertness | Intuitively sense the details of your surroundings |
| Conceal Object | Hide an object on your person or in your environment |
| Disguise | Change your appearance to look like a different person |
| Eavesdrop | Actively listen to something that is hard to hear, such as a whispered conversation through a door |
| Escape Artist | Escape from bonds such as rope or manacles |
| Hide | Conceal yourself from others' observation |
| Pick Lock | Open a lock without using the key |
| Pick Pocket | Steal an item that another person wears or carries without them noticing |
| Sabotage | Disable a mechanical device such as a trap |
| Search | Actively search an environment for important details and items |
| Sneak | Move silently |
| Track | Follow a trail that another creature has left behind |

### Lore — *research and recall; useful on rests/downtime.*

**Reward pattern:** extra piece of useful information.
**Consequence pattern:** learn an *incorrect* but confident-sounding fact — lean into roleplay. Alternatively, Director rolls medium/hard lore tests secretly per hero and narrates outcomes without revealing rolls.

| Skill | Use |
|---|---|
| Criminal Underworld | Knowing about criminal organizations, their crimes, their relationships, and their leaders |
| Culture | Knowing about a culture's customs, folktales, and taboos |
| History | Knowing about significant past events |
| Magic | Knowing about magical places, spells, rituals, items, and phenomena |
| Monsters | Knowing monster ecology, strengths, and weaknesses |
| Nature | Knowing about natural flora, fauna, and weather |
| Psionics | Knowing about psionic places, spells, rituals, items, and phenomena |
| Religion | Knowing about religious mythology, practices, and rituals |
| Rumors | Knowing gossip, legends, and uncertain truths |
| Society | Knowing noble etiquette and the leadership and power dynamics of noble families |
| Strategy | Knowing about battle tactics and logistics |
| Timescape | Knowing about the many worlds of the timescape |

## Assist a Test

One hero helps another's test. Requires **all three**:

1. Assister has a **skill that applies** to the test.
2. The assisted hero isn't using that **same skill**.
3. Assister describes plausibly useful help — yelling encouragement doesn't make someone stealthier.

Assister makes a test with the chosen skill and a characteristic the Director picks from the help method. Assist-test outcome modifies the assisted roll:

| Assist outcome | Effect on the assisted test |
|---|---|
| Failure (any) | **Bane** on their test. |
| Success (any) | **Edge** on their test. |
| Success with a reward | **Double edge** on their test. |

*Example: ally picks jailer's pocket (Agility + Pick Pocket); you distract with Flirt (Presence + Flirt).*

**Design lever.** Assist is how non-specialists contribute to a single-focus test. When designing a test, note which *other* skills could plausibly assist — more assist angles = more participants.

## Director-added skills

Directors can mint new skills to fit a campaign (Brewing, Painting, etc.), assign them a group, and let players swap any skill from that group for the new one.
