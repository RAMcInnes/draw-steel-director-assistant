# Social encounter output template (Interaction mode)

Used when the encounter is light NPC conversation rather than an adventure-changing Negotiation. Output structure:

```markdown
# <Encounter title>

**Type:** Interaction
**Date drafted:** YYYY-MM-DD
**NPC:** <name — see profile below>

## Hook
<one or two sentences — what's happening when the heroes approach this NPC?>

## NPC profile
- **Name + role:** …
- **Distinguishing feature:** <appearance / scent>
- **Voice:** <one-line cue>
- **Behavior:** <one distinct behavior>
- **Flaw:** <one flaw>
- **Kernel of motivation:** <why they'd help — or what would stop them>

## Persuasion-fit
- **Responds to:** <approaches that work>
- **Bounces off:** <approaches that won't work — surface to the heroes through reactions, not blocked rolls>

## Necessary information / objects
- <what the NPC will share freely — required for the adventure to continue>
- …

## Optional information / objects
- <what the NPC will share if persuaded, paid, helped, or convinced via Test — bonus material>
- …

## Out
<how the conversation typically ends — heroes part ways with the NPC alive and on what terms>
```

The Interaction template stays under 1 page in practice. If a user's prep grows past that, the encounter is probably a Negotiation in disguise — prompt to re-classify.
